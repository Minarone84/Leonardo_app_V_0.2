# Leonardo V2 Historical Documentation

This archive preserves useful implementation evidence while keeping it
separate from current operational documentation.

## Archive contents

`docs/history/tasks/`
: Historical task completion records.

`docs/history/merge_notes/`
: Completed merge and reconciliation instructions. Do not execute them against
  the current repository.

`docs/history/workplans/`
: Completed or superseded plans.

`docs/history/governance/`
: Historical notes about governance changes. The repository-root governance
  files remain authoritative.

`docs/history/scratch/`
: Superseded working notes and planning material. This includes
  `RESEARCH_GUI_RESTORATION_INITIAL_NOTES.odt`, a non-authoritative planning
  scratchpad. Scratch material does not define current behavior or acceptance
  criteria.

Nothing under `docs/history/` is authoritative for current application behavior
unless a current governing or operational document explicitly references it.
